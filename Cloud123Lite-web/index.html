Cloud123Lite 是个人学习与技术研究项目，为 123 云盘提供一个无广告、简洁流畅的第三方客户端体验。项目使用 Kotlin、Jetpack Compose 与 Hilt 构建，所有实现都可以在源码中查阅。

本项目为第三方非官方客户端，与 123 云盘官方无关。请遵守相关服务条款及法律法规。
